# Xiaomi MiTV-AXSO2 (Mi TV 4A Pro, India) — Android 11 debloat list
# Source: cleanyourtv examples/xiaomi-mitv-axso2 (tested on a real AXSO2; device reported
#         Android 9 base + Android 11 security build RTT0.211201.001 — verify each package
#         exists on your TV with `pm list packages` before disabling; unlisted = skipped safely).
#
# Every package is DISABLED with `pm disable-user`, never uninstalled. Undo with
# `pm enable <package>` or restore.sh. Comment out any line you want to keep.
#
# NEVER add to this list (quick recovery requires them):
#   com.android.settings, com.android.tv.settings, com.google.android.gsf (Play Services),
#   com.android.vending (Play Store), TV input services (com.android.tv.inputservice / droidlogic),
#   the IME (com.google.android.inputmethod.* Gboard), Bluetooth/input/remote services,
#   android (system), WebView (com.google.android.webviewer / webview).
# TVINPUT_ALLOW=1 would be needed to touch anything with TV_INPUT_HARDWARE permission —
# disabled by default because killing it blacks out HDMI permanently.
#
# Notes from contributors on this model/firmware:
# - USB debugging alone opens network ADB on port 5555.
# - com.mitv.tvhome.atv (PatchWall) disabled = the remote's PatchWall button does nothing.
#   KEPT DISABLED only if our launcher is default; re-enable if you revert.
# - com.google.android.tvrecommendations also feeds the tvlauncher notification panel;
#   if Google sign-in breaks ("Authentication is required"), re-enable
#   com.google.android.tvlauncher and com.google.android.tvrecommendations long enough to sign in,
#   then disable both again.
# - Storage is tight (~600 MB free): run `pm trim-caches 64G` after sign-in if installs fail.
# - After debloat, `svc power reboot` may be killed on dangal firmware; reboot via adb.
